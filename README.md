# 💰 אפליקציה לניהול תקציב משפחתי (Family Budget App)

אפליקציית רשת (Web App) עברית, נקייה ומתקדמת לניהול פיננסי משפחתי וזוגי יומי.
האפליקציה פועלת במצב סטטי מלא, ללא תלות בשרת חיצוני, ושומרת את כל הנתונים באופן בטוח בדפדפן המקומי (LocalStorage) עם אפשרות גיבוי וייצוא קלה לקבצי CSV ו-JSON.

---

## ✨ תכונות מרכזיות

- **🇮🇱 ממשק עברי מלא (RTL):** עיצוב מודרני, נקי וקריא המיועד במיוחד לשימוש זוגי ומשפחתי.
- **📊 דשבורד חכם:**
  - כרטיסיות סיכום (KPI): הכנסות חודשיות, הוצאות, מאזן נטו וגלגול יתרה מצטבר מתחילת השנה.
  - התפלגות הוצאות לפי קטגוריות עם סרגלי התקדמות חזותיים.
  - סיכום חלוקת תנועות לפי אדם (בן זוג 1, בן זוג 2, משותף).
- **📅 מבט שנתי (12 חודשים):** טבלת מטריצה מקיפה של הכנסות, הוצאות ומאזן לכל חודשי השנה.
- **🎯 מעקב יעדי חיסכון:** מעקב אחר קרן חירום, חופשות ועתודות.
- **🔍 סינונים מתקדמים:** סינון לפי חודש, שנה, קטגוריה, סוג (הכנסה/הוצאה/חיסכון), אדם וחיפוש חופשי.
- **🪟 חלונות קופצים (Modals):** יצירה ועריכה נוחה בחלון קופץ ללא טפסים סרובלים בדף.
- **📥 ייבוא וייצוא נתונים:**
  - ייצוא בלחיצת כפתור לקובץ CSV (תואם Excel / Google Sheets בעברית UTF-8 BOM).
  - גיבוי ושחזור מלא בקובץ JSON.
- **🌙 תמיכה בערכת נושא כהה / בהירה (Dark / Light Mode).**

## 🚀 הוראות פריסה ל-GitHub Pages (חינם ללא שרת)

1. **צור ריפוזיטורי חדש ב-GitHub:**
   כנס ל-GitHub וצור ריפוזיטורי חדש (למשל `family-budget`).

2. **העלה את קבצי הפרויקט ל-GitHub:**
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Family Budget App"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/family-budget.git
   git push -u origin main
   ```

3. **הפעל את GitHub Pages:**
   - כנס לריפוזיטורי ב-GitHub -> **Settings** -> **Pages**.
   - תחת **Source**, בחר ב-`Deploy from a branch`.
   - בחר בענף `main` ותקיית `/ (root)` ולחץ **Save**.
   - תוך דקה האתר שלכם יהיה באוויר בכתובת:
     `https://YOUR_USERNAME.github.io/family-budget/`

## 🔒 פרטיות ושמירת נתונים

- האפליקציה פועלת לחלוטין בדפדפן (Client-Side).
- שום נתון פיננסי לא נשלח לשרת חיצוני.
- מומלץ לבצע ייצוא לקובץ CSV/JSON פעם בחודש לשמירת גיבוי ב-Google Drive או במחשב האישי.
